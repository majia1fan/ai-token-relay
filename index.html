不做产品，只做 Token 中转
——卖 Token 到底怎么赚钱

AI 时代最被低估的「中间商」生意：不训练模型、不做应用，只把 Token 转一手，一年就能经手上亿美金。

🔥 在 Product Hunt 上支持

01为什么有人愿意找中间商买

Token 就是 AI 的流量。你发一句话给 ChatGPT，它回一段话，这一来一去消耗的就是 Token，跟手机流量一样，用多少付多少。

问题来了：Claude、GPT、Gemini 官方都卖 Token，为什么还有人找中间商？因为官方直购有四个麻烦——

💳 付款难

海外 AI 的 API 大多只收外币信用卡，很多人根本没有。中转站支持微信、支付宝，人民币直充。

🧩 接口乱

Claude 一个接口、GPT 一个、Gemini 又一个，同时用三家得写三份代码。中转站统一成一个接口，不改代码。

📡 不稳定

官方偶尔风控、限流、维护，你这边就断了。好的中转站挂多条线路，一条挂了自动切另一条，你无感知。

🔒 最疼的是封号

Anthropic 对不支持地区有明确限制，社区里因 IP、支付方式被封号的不在少数。中转站背后有一批 Key 轮换，封一个不影响整体。

顺带一提：Google Antigravity 是「官方正规军路线」（内置 Claude Opus 4，不担心封号），但 Github 上已有人导出其额度（opencode-antigravity-auth），已有用户因此被 Google 封号——风险自担。说到底用户要的不是神秘渠道，是省事、稳定、门槛低、不总担心被封。

02卖 Token 到底怎么赚钱（三个真实案例）

案例 1 OpenRouter —— 抽 5% 的「高速收费站」

前身是 OpenSea 联合创始人，NFT 凉了之后做这个。接口统一成一个入口，开发者接一次，哪个模型挂了自动切。赚钱方式一句话：你通过它调模型花了多少，它加 5%。

$1亿+年经手调用费
~$500万平台自己赚的
$4000万a16z 投资
$5亿估值

本质不是卖 Claude 或 GPT，而是站在所有模型、所有用户中间赚那个「过路费」。只要大家还在用 AI，收费站就一直有车过。

案例 2 国内中转站（以 vapi.cc / 星火 API 为样本）

  • 1
    卖的不只是 Token。还接语音合成/转写、智能抠图、去水印、PDF 解析、OCR、网页爬虫——更像一个 AI 功能超市。
  • 2
    瞄准 Claude Code 用户。卖点就是「Claude Code 接入说明」——教用户改一行环境变量接入。这类用户最头疼付不了款和被封。
  • 3
    靠代理分销放大收入。兑换码（你招客户我给利润空间）+ 代理值（帮充 ChatGPT Plus 赚手续费）。
  • 4
    底层是开源框架。页面标题写的就是「New API」——基于 One-API 二次开发的开源项目。

低价 Token 是鱼饵，不是利润。真正赚钱的是 Claude Code 代接入 + 多功能打包 + 代理分销。

案例 3 One-API —— 自己搭一个中转站？

GitHub 3 万+ star，最多人用的方案。把 Claude / GPT / Gemini 的 Key 填进去，自动统一成一个接口，自带负载均衡、计费、多号轮询；Docker 跑几行命令就能部署。

启动成本：

源码：免费（开源） 服务器：$200–500 / 月 API 额度：¥500–3000 域名杂费：¥200–1000 合计约 ¥1000–5000

搭起来不难，获客和留存才是真问题。技术门槛已被开源压低，真正的门槛是获客、信任、持续运营。

03真有那么赚吗？

别信「每月跑 1000 万 Token、加价 15%、月入 XX」的账——跑便宜模型和贵模型，收入能差十倍。更靠谱的看法是：你的平台一个月跑多少调用量，你从中赚了百分之多少。

🪙 Token 差价

上游 3–5%，中间商 30–50% 能赚，但容易被价格战打穿。

🔁 订阅 / SaaS

卖会员、卖配额、卖团队——比差价稳。

🏢 企业服务

私有部署、定制、出报表——单子大，但要投人力。

📦 行业打包

Agent + 知识库 + 自动化 一条龙，溢价最高。

04别踩坑

⚠️ 三条红线

  • 1
    单一上游风险。只有一条上游、一个收费渠道、没有监控告警，上游一出问题代理就瘫。
  • 2
    别吹「比官方便宜」。模型厂商一直在降价，今天靠差价活，明天上游降一刀利润就没了。
  • 3
    别搞灰产。能长久的都明说「我是中转服务，不是借官方 Key」。红线：封号、法律、纳税、平台合规。

怎么稳？只用正规上游；跟用户说清自己只是中转；备多条线路；别一上来就收大钱。作为用户，你也可以用这些规则去筛选中转站。

写在最后

OpenRouter 一年流水 1 亿美金，不是因为它卖 Token 便宜，而是它承接了几百个模型供应商的麻烦事，变成开发者只需买一次的简单事。

国内中转站能活，也不是因为它比官方便宜，而是因为很多人愿意为人民币支付、不用折腾、不被封号、出了问题有人响应工单。

AI 时代，光倒 Token 赚不了大钱；但帮别人省去各种麻烦、让他们用上 AI，就能赚到钱。
